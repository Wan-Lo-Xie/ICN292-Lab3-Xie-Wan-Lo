# Laboratorio 3 - Sistemas de Información para la Gestión

Repositorio correspondiente al Laboratorio 3 del ramo **Sistemas de Información para la Gestión (ICN292)**.

En este laboratorio se trabajó con **n8n**, desarrollando distintos workflows para procesar las solicitudes entregadas y automatizar parte del flujo de información.

## Parámetros utilizados

Para el desarrollo del laboratorio se utilizaron los siguientes valores:

* S = 280
* U = 60000

## Contenido del repositorio

El repositorio está dividido en las siguientes carpetas:

* `capturas/`: contiene las capturas utilizadas como evidencia del funcionamiento de los workflows.
* `docs/`: contiene el informe y la documentación del laboratorio.
* `json/`: contiene los workflows de n8n exportados en formato JSON.

## Workflows

Durante el laboratorio se desarrollaron principalmente los siguientes workflows:

### Triage

Se encarga de procesar las solicitudes y clasificarlas según las condiciones definidas en el laboratorio.

### Emisor

Se utiliza para procesar las solicitudes que corresponden y generar la información necesaria para su emisión.

### Resumen

Permite obtener un resumen de la información procesada durante la ejecución de los workflows.

## Archivos JSON

Los workflows utilizados en n8n se encuentran guardados dentro de la carpeta `json/`.

Para utilizarlos nuevamente:

1. Abrir n8n.
2. Crear un nuevo workflow.
3. Seleccionar la opción para importar un archivo.
4. Elegir el archivo `.json` correspondiente.
5. Revisar las configuraciones necesarias antes de ejecutarlo.

## Evidencias

Las capturas del desarrollo y ejecución de los workflows se encuentran disponibles en la carpeta `capturas/`.

## Documentación

El informe correspondiente al laboratorio se encuentra dentro de la carpeta `docs/`.
